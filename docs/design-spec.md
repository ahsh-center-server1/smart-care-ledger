# 고정 역할 화면 변경

2026-09-14. 사용자 승인된 제안의 기존 화면 내 변경. 기존 스타일 토큰 유지.

- 권한 등급 선택과 저장 버튼 제거. 직원 역할/담당 배정은 유지.
- 읽기 전용 내 역할·담당 범위·허용 업무 안내. 역할 변경은 직원 관리에서 처리.
- 로딩: 권한 확인 중. 오류: 권한을 확인하지 못해 기능을 잠금.
- 빈 상태: 담당 배정 없음 안내. 정상: 고정 정책에 따른 업무 표시.
- 시스템 관리자 표시는 업무 역할과 별도이며 최종 결재를 암시하지 않는다.
- 승인/대행은 실제 서버 절차가 구현된 기능만 노출한다.
- 모바일 767 이하, 태블릿 768~1023, PC 1024 이상에서 안내를 읽을 수 있게 한다.
- 기존 앱 셸, 색상/간격 토큰 사용. 임의 디자인 전면 개편은 하지 않는다.
