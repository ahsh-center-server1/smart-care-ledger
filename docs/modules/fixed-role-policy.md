# fixed-role-policy

버전: 0.1.1 / 상태: 작성중

## 경계

- 정책: public/domain/ 및 functions/의 동등한 고정 정책.
- 적용: 서버 authz 생성, caller, Rules 및 화면 권한 판정.
- 화면: 권한표 제거·역할 안내·직원 역할/담당 관리.
- 업무 서비스: 보고서 상태·거래 변경·증빙 보존 검사는 서비스에서 수행.

작업 기반 검증 전에는 후속 P1 수정과 운영 이관을 완료 처리하지 않는다.

## 변경 이력

- v0.1.1: 직원 승인을 센터장·시스템 관리자 1회 승인 또는 팀장 요청 후 승인으로 단순화하고, 기존 2단계 대기 건도 한 번에 마무리하도록 변경했다.
