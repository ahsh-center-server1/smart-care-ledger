- ✅ 수기 입력 (날짜/계좌/금액/분류)

- ✅ 의견란 (각 단계별 검토 의견)
- ✅ 반려/수정 처리

- ✅ 연간 통계 (월별 차트, 카테고리 분석)
- ✅ 월별 추이

### 설정 & 관리
- ✅ 직원/입주자/계좌 관리
- ✅ 카테고리 + 자동분류 규칙
- ✅ 고정항목 관리
- ✅ 연간 데이터 마감

### 증빙 관리
- ✅ Google Drive OAuth 업로드
- ✅ 영수증 갤러리 (썸네일 미리보기)
- ✅ 통장 사진 관리

## 👥 역할 & 권한

| 역할 | 권한 |
|------|------|
| **담당자** | 거래 입력, 보고서 작성 및 제출 |
| **팀장** | 담당자 권한 + 1차 결재 (승인/반려) |
| **센터장** | 팀장 권한 + 최종 결재 (승인/반려) + 데이터 마감 |
| **관리자** | 모든 권한 + 직원/권한 관리 |

## 🚀 시작하기

### 1. 로그인
```
웹사이트 접속 → ID/PW 입력 → 로그인
```

### 2. 기본 설정 (관리자)
- 직원 등록
- 입주자 등록
- 계좌 등록 (초기잔액, 기준일)
- 카테고리 설정

### 3. 거래 입력 (담당자)
- 엑셀 업로드 (은행 거래)
- 미분류 항목 카테고리 지정
- 수기입력 (누락 항목)

### 4. 월간 보고서 (담당자 → 팀장 → 센터장)
- 거래 완성 후 보고서 작성
- 담당자 의견 작성
- 팀장 1차 결재
- 센터장 최종 결재

---

## 💡 주요 팁

1. **엑셀 파일은 은행 다운로드 형식 그대로 사용**
   - KB/NH/우리/신한 지원

2. **초기잔액 & 기준일이 정확해야 함**
   - 잔액 계산: 초기잔액 + (기준일 이후 거래)

3. **고정항목 설정 후 월별 일괄 입력**
   - 급여, 공과금 등 고정액 자동화

4. **보고서 제출 전 충분히 검토**
   - 제출 후는 팀장이 반려해야 수정 가능

5. **중복 거래는 엑셀 업로드 시 자동 감지**
   - 미리보기에서 행 삭제 가능

6. **월말 며칠 전에 거래 완성**
   - 보고서 작성 여유 시간 확보

## 🔧 기술 정보

### 파일 구조
```
/public
  ├── index.html              # 전체 HTML + CSS
  ├── app.js                  # 전역 초기화 (~2500줄)
  ├── parser-config.js        # 은행별 엑셀 파서
  ├── firestore.rules         # Firestore 보안 규칙
  ├── modules/                # 기능별 모듈
  │   ├── auth.js
  │   ├── core.js
  │   ├── dashboard.js
  │   ├── transactions.js
  │   ├── report.js
  │   ├── settings.js
  │   └── modals.js
  ├── services/               # 외부 API
  │   ├── firestore.js
  │   └── google-drive.js
  └── utils/                  # 유틸리티
      └── ui.js
```

### Firestore 컬렉션
```
users, clients, accounts, transactions, categories, 
reports, config, fixedItems, archive_YYYY
```

### 인증 방식
- Firestore `users` 컬렉션의 userId/password 직접 비교
- sessionStorage 기반 세션 유지
- Firebase Auth 미사용
