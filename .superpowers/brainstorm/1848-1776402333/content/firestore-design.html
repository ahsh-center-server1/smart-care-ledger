Firestore 저장 구조 + 보안 규칙

권한 설정 데이터가 어디에, 어떻게 저장되고 보호되는지

⚠️ 핵심 제약: Firebase Auth 미사용 현재 앱은 Firestore users 컬렉션으로 직접 인증합니다. Firebase Auth를 쓰지 않기 때문에 Firestore 보안 규칙에서 request.auth가 항상 null입니다.
  • → Firestore rules에서 역할 기반 접근 제어 불가능
  • → 진짜 DB 레벨 보안을 위해서는 Firebase Auth 도입이 필요
  • → 이번 작업 범위: 권한 config 저장/로드 + 규칙 만료 연장
  • → Firebase Auth 전환은 별도 작업으로 분리 (이번 스펙 외)
