## 1. 시스템 개요

### 1.1 목적

**Smart Care Ledger**는 사회복지 시설에서 입주자의 금전을 투명하고 효율적으로 관리하기 위한 웹 기반 시스템입니다. 거래 입력부터 월별 보고서 작성, 팀장·센터장 결재까지 전 과정을 온라인에서 처리할 수 있습니다.

주요 기능:
- 입주자별 계좌 및 거래 내역 관리
- 엑셀(은행 내역서) 자동 업로드 및 분류
- 증빙(영수증) 사진 관리
- 월별 보고서 생성 및 전자 결재
- 연간 통계 및 시각화

### 1.2 접속 URL

| 구분 | 주소 |
|---|---|
| 웹 애플리케이션 | https://smart-care-ledger.web.app |

### 1.3 지원 브라우저

원활한 사용을 위해 아래 브라우저의 **최신 버전** 사용을 권장합니다.

| 브라우저 | 권장 여부 |
|---|---|
| Google Chrome | ✅ 권장 (최신 버전) |
| Microsoft Edge | ✅ 권장 (최신 버전) |
| Safari (macOS/iOS) | ✅ 사용 가능 |
| Firefox | ✅ 사용 가능 |
| Internet Explorer | ❌ 미지원 |

💡 **팁**: 증빙 업로드 및 엑셀 업로드 기능은 Google Chrome에서 가장 안정적으로 동작합니다.

### 1.4 앱으로 설치 (PWA)

Smart Care Ledger는 **PWA(설치형 웹앱)**를 지원합니다. 브라우저 없이 바탕화면·홈 화면 아이콘으로 앱처럼 실행할 수 있습니다.

- **PC (Chrome/Edge)**: 주소창 오른쪽의 **설치(⊕) 아이콘**을 클릭하거나, 브라우저 메뉴 → **앱 설치**를 선택합니다.
- **Android (Chrome)**: 메뉴(⋮) → **앱 설치** 또는 **홈 화면에 추가**를 선택합니다.
- **iPhone (Safari)**: 공유 버튼 → **홈 화면에 추가**를 선택합니다.

💡 **팁**: 설치하면 전체 화면으로 실행되어 화면을 더 넓게 사용할 수 있고, 홈 화면에서 바로 접근할 수 있습니다.

## 2. 로그인 및 역할

### 2.1 로그인 방법

1. 웹 브라우저에서 https://smart-care-ledger.web.app 에 접속합니다.
2. **아이디(userId)**와 **비밀번호(password)**를 입력합니다.
3. **로그인** 버튼을 클릭합니다.

⚠️ **주의**: 아이디와 비밀번호는 관리자가 미리 등록해야 사용할 수 있습니다. 로그인이 되지 않으면 관리자에게 계정 등록을 요청하세요.

### 2.2 세션(로그인 유지)

- 로그인 후 **브라우저 탭을 닫지 않는 한** 로그인 상태가 유지됩니다.
- 브라우저를 완전히 닫거나 탭을 닫으면 세션이 종료되므로, 다음 접속 시 다시 로그인해야 합니다.
- 화면 우측 상단의 **로그아웃** 버튼을 클릭하면 즉시 세션이 종료됩니다.

💡 **팁**: 공용 컴퓨터를 사용하는 경우 반드시 작업 후 **로그아웃**하세요.

### 2.3 역할(Role) 체계

시스템에는 5가지 역할이 있으며, 역할에 따라 접근 가능한 기능이 다릅니다.

| 역할 | 설명 |
|---|---|
| **담당자** | 입주자를 직접 담당하는 직원. 거래 입력, 보고서 작성·제출 가능 |
| **팀장** | 담당자 권한 + 보고서 1차 결재, 반려, 설정 관리 가능 |
| **센터장** | 팀장 권한 + 보고서 최종 결재(2차), 데이터 마감 가능 |
| **관리자** | 모든 권한 보유. 시스템 전체 관리 |
| **입력자** | 거래 입력 전용. 보고서와 설정 메뉴에 접근 불가 |

### 2.4 역할별 기능 권한표

| 기능 | 담당자 | 팀장 | 센터장 | 관리자 | 입력자 |
|---|:---:|:---:|:---:|:---:|:---:|
| 거래내역 조회 | ✅ | ✅ | ✅ | ✅ | ✅ |
| 거래 입력/수정 | ✅ | ✅ | ✅ | ✅ | ✅ |
| 보고서 작성·제출 | ✅ | ✅ | ✅ | ✅ | ❌ |
| 보고서 1차 결재 (팀장) | ❌ | ✅ | ✅ | ✅ | ❌ |
| 보고서 최종 결재 (센터장) | ❌ | ❌ | ✅ | ✅ | ❌ |
| 설정 메뉴 접근 | ❌ | ✅ | ✅ | ✅ | ❌ |
| 데이터 마감 | ❌ | ❌ | ✅ | ✅ | ❌ |
| 권한 관리 · 전체 초기화 | ❌ | ❌ | ❌ | ❌ | ✅ |

💡 **참고**: 위 권한은 **기본값**입니다. 관리자는 **설정 > 권한** 메뉴에서 역할별로 각 기능(거래 입력/삭제, 엑셀 업로드, 증빙, 보고서 결재, 설정 접근 등)의 허용 여부를 세부적으로 조정할 수 있습니다. 변경한 권한은 각 사용자의 다음 로그인부터 적용됩니다.

## 3. 대시보드

### 3.1 화면 구성

로그인하면 **대시보드**가 표시됩니다. 대시보드에는 내가 담당하는 **입주자 카드**가 격자(그리드) 형태로 나열됩니다.

각 카드에는 다음 정보가 표시됩니다:

| 항목 | 설명 |
|---|---|
| **입주자 이름** | 카드 상단에 크게 표시 |
| **계좌 수** | 해당 입주자의 등록된 계좌 개수 |
| **총 잔액** | 모든 계좌의 잔액 합계 |

- 잔액이 **양수(+)**이면 초록색으로 표시됩니다.
- 잔액이 **음수(-)**이면 빨간색으로 표시됩니다.

### 3.2 퀵 액션 버튼

대시보드 상단에는 자주 쓰는 기능으로 바로 이동하는 **퀵 액션 버튼**이 있습니다.

| 버튼 | 기능 |
|---|---|
| 📤 파일 업로드 | 은행 엑셀 파일 업로드 창 열기 |
| 🏦 통장 사진 | 입주자·계좌·연월을 선택해 통장 사진 업로드 |
| 📋 거래내역 | 거래내역 화면으로 이동 |
| ✍️ 수기 입력 | 수기 입력 창 열기 |
| 📑 보고서 | 보고서 화면으로 이동 |

### 3.3 거래내역으로 이동

입주자 카드를 **클릭**하면 해당 입주자의 거래내역 화면으로 자동 이동합니다.

💡 **팁**: 팀장·센터장·관리자는 자신이 담당하지 않는 입주자의 카드도 조회할 수 있습니다.

## 4. 거래내역

### 4.1 화면 구성

거래내역 화면은 크게 **필터 영역**과 **거래 목록** 두 부분으로 구성됩니다.

### 4.2 필터 및 검색

거래내역 상단의 필터를 이용해 원하는 거래만 조회할 수 있습니다.

| 필터 항목 | 설명 |
|---|---|
| **입주자** | 조회할 입주자 선택 |
| **계좌** | 입주자 선택 시 해당 입주자의 계좌 목록이 자동 갱신됨 |
| **구분** | 수입 / 지출 / 자산이동 / 취소 중 선택 |
| **증빙** | 있음 / 없음 중 선택 |
| **기간** | 시작일 ~ 종료일 직접 입력 |
| **키워드** | 내용(description)에 포함된 단어로 검색 |

**빠른 기간 선택 버튼**:

| 버튼 | 조회 범위 |
|---|---|
| 이번달 | 이번 달 1일 ~ 오늘 |
| 지난달 | 지난 달 전체 |
| 3개월 | 최근 3개월 |
| 전체 | 전체 기간 |

### 4.3 정렬

컬럼 헤더를 클릭하면 해당 컬럼 기준으로 정렬됩니다. 한 번 더 클릭하면 역순으로 정렬됩니다.

| 정렬 가능 컬럼 | 설명 |
|---|---|
| 날짜 | 거래 날짜 기준 정렬 (기본: 오름차순) |
| 카테고리 | 분류 기준 정렬 |
| 내용 | 거래 내용 기준 정렬 |
| 계좌 | 계좌명 기준 정렬 |
| 수입 | 수입 금액 기준 정렬 |
| 지출 | 지출 금액 기준 정렬 |
| 증빙 | 증빙 유무 기준 정렬 |

### 4.4 드래그앤드롭 순서 변경

같은 날짜 안에서 거래 순서를 조정하고 싶을 때 사용합니다.

1. 순서를 바꾸고 싶은 거래 행의 **왼쪽 끝 핸들(≡)**을 클릭한 채 위아래로 끌어다 놓습니다.
2. 원하는 위치에 놓으면 순서가 저장됩니다.

⚠️ **주의**: 드래그앤드롭은 **현재 페이지 내**에서만 순서를 변경할 수 있습니다. 페이지를 넘어가는 순서 변경은 지원되지 않습니다.

### 4.5 페이지네이션

- 한 페이지에 **100건**씩 표시됩니다.
- 페이지 하단의 번호를 클릭하여 다음 페이지로 이동합니다.

### 4.6 달력 뷰 / 목록 뷰 전환

화면 우측 상단의 아이콘 버튼으로 뷰를 전환할 수 있습니다.

| 버튼 | 뷰 종류 |
|---|---|
| ☰ | 목록(리스트) 뷰 |
| 🗓️ | 달력(캘린더) 뷰 |

달력 뷰에서는 날짜별로 거래 건수와 금액을 한눈에 확인할 수 있습니다.

### 4.7 CSV 내보내기

현재 필터가 적용된 거래 목록 전체를 CSV 파일로 다운로드할 수 있습니다.

1. 원하는 필터 조건을 설정합니다.
2. **CSV 내보내기** 버튼을 클릭합니다.
3. 파일이 자동으로 다운로드됩니다.

### 4.8 카테고리 인라인 편집

거래 목록에서 카테고리를 빠르게 수정할 수 있습니다.

1. 수정할 거래의 **카테고리 칩(chip)**을 클릭합니다.
2. 드롭다운 메뉴에서 원하는 카테고리를 선택합니다.
3. 선택 즉시 저장됩니다.
4. 빈 공간을 클릭하면 드롭다운이 닫힙니다.

💡 **팁**: 카테고리 드롭다운에는 자주 사용하는 순서로 카테고리가 정렬됩니다. 카테고리 관리에서 순서를 조정할 수 있습니다.

### 4.9 일괄 삭제

여러 거래를 한 번에 삭제할 수 있습니다.

1. 삭제할 거래 행의 **체크박스**를 클릭하여 선택합니다.
2. 상단에 나타나는 **삭제** 버튼을 클릭합니다.
3. 확인 메시지에서 **확인**을 클릭하면 삭제됩니다.

⚠️ **주의**: 삭제된 거래는 복구할 수 없습니다. 신중하게 선택하세요.

### 4.10 거래 유형 뱃지

각 거래는 유형에 따라 뱃지(badge)로 표시됩니다.

| 유형 | 뱃지 색상 | 잔액 반영 | 수입/지출 집계 포함 |
|---|---|:---:|:---:|
| 수입 | 초록 | ✅ | ✅ |
| 지출 | 빨강 | ✅ | ✅ |
| 자산이동 | 파랑 | ✅ | ❌ |
| 취소 | 회색 | ❌ | ❌ |

## 5. 수기 입력

### 5.1 수기 입력 폼 열기

**수기 입력** 창(모달)은 다음 위치에서 열 수 있습니다.

- **대시보드** 퀵 액션의 **✍️ 수기 입력** 버튼
- **거래내역** 화면 상단의 **✍️ 수기 입력** 버튼
- 좌측 사이드바의 **✍️ 수기 입력** 버튼(PC)

### 5.2 공통 입력 항목

모든 거래 유형에서 공통으로 입력하는 항목입니다.

| 항목 | 설명 | 필수 여부 |
|---|---|:---:|
| 날짜 | 거래 발생 날짜 | ✅ |
| 시간 | 거래 발생 시간 | ❌ |
| 계좌 | 거래가 발생한 계좌 선택 | ✅ |
| 유형 | 수입 / 지출 / 자산이동 / 취소 중 선택 | ✅ |
| 금액 | 거래 금액 (숫자만 입력) | ✅ |
| 카테고리 | 분류 선택 | ✅ |
| 소분류 | 세부 분류 선택 | ❌ |
| 내용 | 거래 내용(메모) | ❌ |
| 증빙 | 영수증 사진 첨부 | ❌ |

### 5.3 유형별 입력 방법

#### 5.3.1 수입 입력

1. **유형**에서 **수입**을 선택합니다.
2. 입금된 계좌를 선택합니다.
3. 금액, 카테고리, 내용을 입력합니다.
4. **저장** 버튼을 클릭합니다.

**수입 예시**: 연금, 급여, 지원금 등

#### 5.3.2 지출 입력

1. **유형**에서 **지출**을 선택합니다.
2. 출금된 계좌를 선택합니다.
3. 금액, 카테고리, 내용을 입력합니다.
4. 영수증이 있다면 **증빙** 항목에 파일을 첨부합니다.
5. **저장** 버튼을 클릭합니다.

💡 **팁**: 카드 환불 등 음수 지출의 경우, 금액 앞에 `-`(마이너스)를 붙여 입력합니다. 예: `-5000`

#### 5.3.3 자산이동 입력 (계좌 간 이체)

자산이동은 한 계좌에서 다른 계좌로 돈을 옮길 때 사용합니다. 입력하면 **출금 거래**와 **입금 거래** 2건이 자동으로 생성되어 두 계좌 잔액에 각각 반영됩니다.

1. **유형**에서 **자산이동**을 선택합니다.
2. **출금 계좌**(돈이 나가는 계좌)를 선택합니다.
3. **입금 계좌**(돈이 들어오는 계좌)를 선택합니다.
4. 금액을 입력합니다.
5. 내용을 입력합니다.
6. **저장** 버튼을 클릭합니다.

⚠️ **주의**: 자산이동 거래는 수입/지출 집계에 포함되지 않습니다. 단순히 계좌 간 잔액 이동만 반영됩니다.

#### 5.3.4 취소 입력 (카드 승인 취소)

카드 승인이 취소된 경우에 사용합니다.

1. **유형**에서 **취소**를 선택합니다.
2. 해당 계좌를 선택합니다.
3. 취소된 금액과 내용을 입력합니다.
4. **저장** 버튼을 클릭합니다.

⚠️ **주의**: 취소 거래는 잔액 계산과 수입/지출 집계에 **포함되지 않습니다**.

### 5.4 고정항목 일괄 입력

매월 반복되는 고정 지출/수입을 한 번에 입력할 수 있습니다.

1. **거래내역** 화면 상단의 **📌 고정항목 입력** 버튼을 클릭합니다.
2. 이번 달에 아직 입력되지 않은 고정항목 목록이 표시됩니다.
3. 확인 후 **일괄 입력** 버튼을 클릭하면 해당 월의 고정항목이 모두 자동 입력됩니다.

💡 **팁**: 같은 달에 이미 입력된 고정항목은 중복으로 다시 입력되지 않습니다.

## 6. 엑셀 업로드

은행에서 내려받은 거래 내역 파일을 시스템에 바로 업로드할 수 있습니다.

### 6.1 지원 형식

| 은행/형식 | 파일 형식 |
|---|---|
| KB국민은행 | XLS/XLSX |
| KB국민카드 | XLS/XLSX |
| NH농협은행 | XLS/XLSX |
| NH농협카드 | XLS/XLSX |
| 우리은행 | XLS/XLSX |
| 신한은행 | XLS/XLSX |
| SMS XML | XML |
| HTML-XLS | HTML/XLS |

💡 **팁**: 각 은행 인터넷뱅킹 또는 모바일앱에서 "거래내역 내보내기(엑셀)" 기능을 사용하여 파일을 내려받으세요.

### 6.2 업로드 방법

1. **대시보드**의 **📤 파일 업로드** 퀵 액션 또는 **거래내역** 화면 상단의 **📂 파일 업로드** 버튼을 클릭합니다.
2. **입주자**와 **계좌**를 선택합니다.
3. 파일을 드래그앤드롭하거나 **파일 선택** 버튼으로 업로드할 파일을 선택합니다.
4. 파일이 인식되면 **거래 미리보기** 화면이 표시됩니다.

### 6.3 미리보기 및 확인

미리보기 화면에서 업로드될 거래 내역을 검토할 수 있습니다.

- **행 삭제**: 불필요한 행의 **삭제(X)** 버튼을 클릭하여 제외할 수 있습니다.
- **자동분류 결과**: 각 거래에 자동으로 분류된 카테고리가 표시됩니다.
- **중복 경고**: 동일 날짜·동일 금액의 거래가 이미 존재하면 ⚠️ 중복 의심 뱃지가 표시됩니다.

### 6.4 자동분류 규칙

업로드 시 시스템이 거래 내용의 키워드를 분석하여 카테고리를 자동으로 지정합니다.

- **우선순위**: 입주자별 전용 규칙이 공통 규칙보다 먼저 적용됩니다.
- 자동분류가 잘못된 경우, 미리보기 화면에서 직접 수정하거나, 저장 후 거래내역에서 카테고리 인라인 편집으로 수정할 수 있습니다.

### 6.5 중복 경고 처리

⚠️ 중복 의심 뱃지가 표시된 거래는 이미 입력된 거래와 날짜·금액이 같습니다.

- 실제 중복이라면 해당 행을 **삭제**하고 업로드합니다.
- 중복이 아니라면(같은 날 동일 금액의 다른 거래) 그대로 두고 업로드합니다.

### 6.6 업로드 완료

미리보기에서 검토를 마치고 **저장** 버튼을 클릭하면 모든 거래가 시스템에 저장됩니다.

### 6.7 수동 템플릿

은행 파일 형식을 사용하기 어려운 경우, **수동 입력 템플릿**을 다운로드하여 직접 작성한 후 업로드할 수 있습니다.

1. 엑셀 업로드 화면에서 **템플릿 다운로드** 버튼을 클릭합니다.
2. 다운로드된 엑셀 파일에 거래 내역을 입력합니다.
3. 저장 후 동일한 방법으로 업로드합니다.

## 7. 증빙 관리

거래의 영수증, 입금 확인서 등 증빙 자료를 Google Drive에 업로드하여 관리합니다.

### 7.1 증빙 업로드 방법

#### 수기 입력 시 첨부

1. 수기 입력 폼에서 **증빙** 항목의 **파일 선택** 버튼을 클릭하거나, 이미지 파일을 드래그앤드롭합니다.
2. 선택된 이미지가 압축(최대 1200px, JPEG 품질 0.78)되어 Google Drive에 자동 업로드됩니다.
3. 업로드 완료 후 미리보기 썸네일이 표시됩니다.

#### 거래내역에서 사후 첨부

1. 거래내역 목록에서 증빙을 추가할 거래를 클릭합니다.
2. **증빙 추가** 버튼을 클릭합니다.
3. 이미지 파일을 선택하면 업로드됩니다.

### 7.2 증빙 미리보기

- 거래 목록에서 증빙 아이콘을 클릭하면 영수증 이미지를 미리볼 수 있습니다.
- 이미지는 Google Drive 썸네일 API를 통해 로드됩니다.

### 7.3 영수증 A4 일괄 출력

여러 영수증을 한 번에 A4 용지에 인쇄할 수 있습니다.

1. 출력할 거래들의 **체크박스**를 선택합니다.
2. **영수증 출력** 버튼을 클릭합니다.
3. 인쇄 미리보기 창이 열립니다. 영수증은 **2열 × 4행(한 페이지 8개)** 형식으로 배치됩니다.
4. 브라우저의 인쇄 기능을 사용하여 출력합니다.

💡 **팁**: 영수증 출력 시 브라우저 인쇄 설정에서 **여백을 최소**로 설정하면 더 많은 영수증을 한 페이지에 인쇄할 수 있습니다.

## 8. 통장 사진

계좌별로 통장 사진(통장 거래내역 사진)을 월별로 관리합니다.

## 9. 카테고리 및 자동분류 규칙

### 9.1 카테고리 종류

시스템에는 두 가지 종류의 카테고리가 있습니다.

| 종류 | 설명 |
|---|---|
| **공통 카테고리** | 모든 입주자에게 공통으로 사용되는 분류 |
| **입주자별 전용 카테고리** | 특정 입주자에게만 적용되는 분류 |

### 9.2 카테고리 관리 (설정 메뉴)

**설정 > 카테고리 관리** 에서 카테고리를 추가·삭제·정렬할 수 있습니다.

#### 카테고리 추가

1. **+ 카테고리 추가** 버튼을 클릭합니다.
2. 카테고리명을 입력합니다.
3. **저장**을 클릭합니다.

#### 카테고리 순서 변경

- 카테고리 목록에서 항목을 **드래그앤드롭**하여 순서를 변경합니다.
- 이 순서가 거래 입력 시 카테고리 드롭다운의 표시 순서에 반영됩니다.

💡 **팁**: 자주 사용하는 카테고리를 목록 위쪽으로 이동시키면 입력 속도가 빨라집니다.

#### 카테고리 삭제

- 삭제할 카테고리 옆의 **삭제(X)** 버튼을 클릭합니다.

⚠️ **주의**: 이미 거래에 사용 중인 카테고리를 삭제하면 기존 거래의 카테고리가 비어있는 상태가 될 수 있습니다.

### 9.3 자동분류 규칙

엑셀 업로드 또는 거래 입력 시 내용(키워드)을 분석하여 카테고리를 자동으로 지정하는 규칙입니다.

#### 규칙 우선순위

```
입주자별 전용 규칙  →  공통 규칙 순서로 적용
```

같은 키워드가 두 규칙에 모두 있다면 **입주자별 전용 규칙**이 우선 적용됩니다.

#### 규칙 추가 방법

1. **설정 > 자동분류 규칙**으로 이동합니다.
2. **+ 규칙 추가** 버튼을 클릭합니다.
3. **키워드**: 거래 내용에서 찾을 단어를 입력합니다. (예: `편의점`, `이마트`)
4. **카테고리**: 키워드가 발견되었을 때 지정할 카테고리를 선택합니다.
5. **저장**을 클릭합니다.

#### 규칙 예시

| 키워드 | 카테고리 | 소분류 |
|---|---|---|
| 편의점 | 생활용품 | 잡비 |
| 이마트 | 식비 | 장보기 |
| 약국 | 의료비 | 약값 |
| ATM | 현금출금 | — |

## 10. 고정항목

### 10.1 고정항목이란?

매월 일정한 날에 반복되는 거래(예: 매월 5일 식비 지원, 매월 25일 관리비 등)를 미리 등록해 두는 기능입니다.

### 10.2 고정항목 등록

**설정 > 고정항목 관리** 에서 등록합니다.

1. **+ 고정항목 추가** 버튼을 클릭합니다.
2. 다음 항목을 입력합니다:

| 항목 | 설명 |
|---|---|
| 입주자 | 해당 입주자 선택 |
| 계좌 | 거래가 발생할 계좌 선택 |
| 유형 | 수입 / 지출 선택 |
| 매월 몇 일 | 거래가 발생하는 날짜 (예: 5) |

| 금액 | 거래 금액 입력 |

### 10.3 고정항목 일괄 입력

2. 이번 달에 아직 입력되지 않은 고정항목 목록이 표시됩니다.
3. **일괄 입력** 버튼을 클릭하면 해당 항목들이 모두 입력됩니다.

⚠️ **주의**: 같은 달에 이미 입력된 고정항목은 중복으로 입력되지 않습니다. 실수로 두 번 클릭해도 중복 입력이 발생하지 않습니다.

💡 **팁**: 월초에 고정항목을 먼저 일괄 입력한 후, 그 달의 추가 거래를 하나씩 입력하면 효율적입니다.

## 11. 보고서

### 11.1 보고서란?

매월 입주자의 금전 관리 내역을 정리하여 작성하는 공식 문서입니다. 담당자가 작성하고, 팀장과 센터장이 단계적으로 결재합니다.

### 11.2 결재 흐름

```
작성(초안)  →  제출(담당자)  →  1차 결재(팀장)  →  최종 결재(센터장)
                                        ↑                       ↓
                                    반려(어느 단계에서나 가능)
                                        ↓
                              담당자가 수정 후 재제출
```

| 상태 | 설명 |
|---|---|
| **draft** (초안) | 작성 중이거나 반려된 상태 |
| **submitted** (제출) | 담당자가 제출 완료, 팀장 결재 대기 |
| **team_approved** (1차 결재) | 팀장 결재 완료, 센터장 결재 대기 |
| **confirmed** (최종 결재) | 센터장 최종 결재 완료 |

⚠️ **중요**: 팀장 결재가 완료되어야만 센터장이 최종 결재를 진행할 수 있습니다. 순서를 건너뛸 수 없습니다.

### 11.3 특수 케이스: 팀장이 직접 담당하는 입주자

팀장이 해당 입주자를 직접 담당하는 경우(담당 직원 없음), 보고서 제출과 1차 결재가 **동시에 처리**됩니다.

### 11.4 보고서 생성 방법

1. 좌측 메뉴(또는 모바일 하단 바)에서 **보고서** 탭을 클릭합니다.
2. **📋 월간 보고서** 서브탭이 선택된 상태에서 **입주자 · 연도 · 월**을 선택합니다.
   - 보고서 탭에는 **📋 월간 보고서**와 **📈 연간 통계** 두 개의 서브탭이 있습니다.
3. **📊 조회** 버튼을 클릭합니다.
4. 시스템이 해당 월의 거래 내역을 자동으로 불러와 보고서를 생성합니다.
5. 각 섹션을 검토하고 담당자 의견을 작성한 뒤 저장·제출합니다.

### 11.5 보고서 구성 섹션

생성된 보고서는 다음 섹션으로 구성됩니다.

#### 계좌 현황

| 항목 | 설명 |
|---|---|
| 기초 잔액 | 보고서 월의 1일 기준 잔액 (초기잔액 + 기준일 이후 ~ 전월 말 거래 합산) |
| 수입 합계 | 해당 월의 수입 총액 |
| 지출 합계 | 해당 월의 지출 총액 |
| 기말 잔액 | 기초 잔액 + 해당 월 수입 - 해당 월 지출 |

#### 분류별 지출

- 지출 카테고리별 금액과 비율이 **막대 시각화**로 표시됩니다.
- 비율이 높은 순서로 정렬됩니다.

#### 거래 목록

- 해당 월의 모든 거래가 날짜 순으로 표시됩니다.
- **드래그앤드롭**으로 순서를 조정할 수 있습니다.

#### 통장 사진

- 해당 월에 업로드된 통장 사진이 자동으로 표시됩니다.

#### 의견란

담당자, 팀장, 센터장이 각각 의견을 입력할 수 있습니다.

| 구분 | 입력 가능 시점 |
|---|---|
| 담당자 의견 | 보고서 작성 및 제출 시 |
| 팀장 의견 | 1차 결재 또는 반려 시 |
| 센터장 의견 | 최종 결재 또는 반려 시 |

#### 결재란

- 담당자, 팀장, 센터장의 결재 도장(스탬프)이 표시됩니다.
- 결재 완료 시 해당 결재란에 결재자 이름과 날짜가 기록됩니다.

#### 자동 분석

- 시스템이 규칙 기반으로 해당 월 금전 관리를 자동 분석한 내용이 표시됩니다.
- 특이사항, 대규모 지출 등을 자동으로 감지하여 안내합니다.

#### 월별 추이 차트

- 최근 6개월의 수입·지출 추이를 차트로 볼 수 있습니다.

### 11.6 보고서 결재 방법

#### 담당자: 보고서 제출

1. 보고서를 작성하고 내용을 검토합니다.
2. 필요한 경우 **담당자 의견**을 입력합니다.
3. **제출** 버튼을 클릭합니다.
4. 상태가 **submitted(제출)**로 변경됩니다.

💡 **제출 회수(recall)**: 팀장이 아직 1차 결재하지 않은 상태(submitted)라면, 담당자 본인이 **↩ 회수** 버튼을 눌러 보고서를 초안(draft)으로 되돌릴 수 있습니다. 이 경우 팀장의 반려를 기다리지 않고 바로 수정 후 다시 제출할 수 있습니다. (팀장이 이미 결재했다면 회수할 수 없으며, 반려를 받아야 수정할 수 있습니다.)

#### 팀장: 1차 결재

1. 상단 메뉴 **보고서** 탭에서 결재 대기 목록을 확인합니다. (네비게이션 뱃지로 대기 건수 표시)
2. 결재할 보고서를 클릭합니다.
3. 내용을 검토합니다.
4. **승인**: **1차 결재** 버튼 클릭 → 상태가 **team_approved**로 변경됩니다.
5. **반려**: 팀장 의견에 반려 사유를 입력하고 **반려** 버튼 클릭 → 상태가 **draft**로 되돌아갑니다.

#### 센터장: 최종 결재

1. 팀장 결재가 완료된 보고서만 목록에 표시됩니다.
2. 결재할 보고서를 클릭합니다.
3. **최종 결재**: **최종 결재** 버튼 클릭 → 상태가 **confirmed**로 변경됩니다.
4. **반려**: 센터장 의견 입력 후 **반려** 버튼 클릭 → 상태가 **draft**로 되돌아갑니다.

#### 담당자: 반려 후 재제출

1. 반려된 보고서를 열어 팀장/센터장의 반려 의견을 확인합니다.
2. 내용을 수정하고 담당자 의견을 입력합니다.
3. **다시 제출** 버튼을 클릭합니다.

### 11.7 보고서 수정 및 삭제

- **수정**: 초안(draft) 상태에서만 자유롭게 수정할 수 있습니다. 제출 이후 수정이 필요하면 **① 팀장 결재 전에는 담당자가 직접 회수(↩)**, **② 결재 이후에는 팀장·센터장의 반려**를 통해 초안으로 되돌린 뒤 수정합니다.

> 🔒 **최종 결재(confirmed) 완료 월의 거래 잠금**: 최종 결재가 완료된 월에는 해당 입주자의 거래를 **추가·수정·삭제할 수 없습니다**(수기입력, 자산이동, 엑셀 업로드, 고정항목 입력, 카테고리 변경, 순서 변경, 증빙 첨부 모두 차단). 정정이 필요하면 센터장이 **결재 취소**로 되돌린 뒤 수정합니다.
> 단, **관리자**로 로그인한 경우에는 최종 결재 완료 월에도 예외적으로 추가·수정·삭제가 가능합니다.
- **삭제**: 팀장·센터장·관리자가 초안 또는 제출 상태의 보고서를 삭제할 수 있습니다.

⚠️ **주의**: 최종 결재(confirmed) 상태의 보고서는 삭제할 수 없습니다.

### 11.8 보고서 내보내기 및 인쇄

#### 엑셀 저장

- 보고서 화면에서 **엑셀 저장** 버튼을 클릭하면 보고서 내용이 엑셀 파일로 다운로드됩니다.

#### 인쇄/PDF 저장

1. **인쇄** 버튼을 클릭합니다.
2. 브라우저의 인쇄 창이 열립니다.
3. **PDF로 저장**을 선택하면 PDF 파일로 저장할 수 있습니다.

💡 **팁**: 인쇄 설정에서 **A4 용지, 여백 최소**로 설정하세요. 보고서는 A4 기준 15px 글씨 크기로 최적화되어 있습니다.

### 11.9 결재 대기 알림

상단 네비게이션의 **보고서** 메뉴에 숫자 뱃지가 표시되면, 내가 결재해야 할 보고서가 있다는 의미입니다.

- 팀장: 담당 입주자의 제출된 보고서 건수
- 센터장: 1차 결재 완료된 보고서 건수

## 12. 연간 통계

### 12.1 연간 통계 화면

**보고서** 메뉴로 이동한 뒤 **📈 연간 통계** 서브탭을 클릭하고, **입주자 · 연도**를 선택한 후 **📈 조회**를 누르면 해당 입주자의 연간 금전 현황을 시각적으로 확인할 수 있습니다.

화면 상단에는 **연간 수입 · 연간 지출 · 연간 잔액** 요약 카드가 표시됩니다.

### 12.2 월별 수입/지출 차트

- 1월~12월의 수입과 지출을 **막대 차트**로 표시합니다.
- 수입(초록)과 지출(빨강)을 한눈에 비교할 수 있습니다.

⚠️ **참고**: 자산이동과 취소 유형의 거래는 차트에 포함되지 않습니다.

### 12.3 카테고리 순위

- 해당 연도의 지출을 카테고리별로 집계하여 금액이 많은 순으로 표시합니다.
- 어떤 항목에 가장 많은 지출이 발생했는지 파악하는 데 유용합니다.

### 12.4 월별 상세 테이블

- 각 월의 수입 합계, 지출 합계, 잔액을 표 형식으로 보여줍니다.
- 특정 월을 클릭하면 해당 월의 상세 내역으로 이동할 수 있습니다.

### 12.5 예산 대비 실적

- **설정 > 예산 관리**에서 입주자별 연간 예산을 카테고리별로 등록하면, 연간 통계에서 **예산 대비 실제 지출**을 비교하여 확인할 수 있습니다.
- 예산 초과 여부를 한눈에 파악하여 다음 해 예산 계획에 활용할 수 있습니다.

## 13. 설정

⚠️ **주의**: 설정 메뉴는 **팀장, 센터장, 관리자**만 접근할 수 있습니다.

설정 화면은 다음 탭으로 구성됩니다.

| 탭 | 내용 | 접근 |
|---|---|---|
| **목록** | 직원 · 입주자 · 계좌 관리 | 팀장 이상 |
| **카테고리** | 관리 대상 / 지출 / 수입 / 자동분류 규칙 | 팀장 이상 |
| **고정 수입/지출** | 고정항목 등록·관리 | 담당자 이상 |
| **예산 관리** | 입주자별 연간 예산 설정 | 팀장 이상 |
| **데이터 초기화/마감** | 연도별 마감, 전체 초기화 | 센터장·관리자 |
| **권한** | 역할별 권한 커스터마이징 | 관리자 |

### 13.1 직원 관리

**설정 > 직원 관리** 에서 시스템 사용자를 추가·수정·삭제합니다.

#### 직원 추가

1. **+ 직원 추가** 버튼을 클릭합니다.
2. 다음 정보를 입력합니다:

| 항목 | 설명 |
|---|---|
| 아이디 (userId) | 로그인에 사용할 아이디 |
| 비밀번호 | 초기 비밀번호 설정 |
| 이름 | 직원 성명 |
| 역할 | 담당자 / 팀장 / 센터장 / 관리자 / 입력자 중 선택 |
| 팀 | 소속 팀 이름 (선택사항) |

3. **저장**을 클릭합니다.

#### 직원 수정

- 직원 목록에서 해당 직원을 클릭하면 정보를 수정할 수 있습니다.
- 비밀번호 초기화 등 변경 사항을 저장합니다.

#### 직원 삭제

- 직원 목록에서 삭제할 직원의 **삭제** 버튼을 클릭합니다.

⚠️ **주의**: 직원을 삭제하면 해당 직원이 담당하던 입주자 배정도 해제됩니다.

### 13.2 입주자 관리

**설정 > 입주자 관리** 에서 입주자를 추가·수정하거나 활성/비활성 상태를 변경합니다.

#### 입주자 추가

1. **+ 입주자 추가** 버튼을 클릭합니다.
2. 다음 정보를 입력합니다:

| 항목 | 설명 |
|---|---|
| 입주자 ID | 고유 식별자 (자동 생성 또는 직접 입력) |
| 이름 | 입주자 성명 |
| 담당 직원 | 담당 직원 선택 (복수 선택 가능) |
| 팀장 | 담당 팀장 선택 |
| 연락처 | 비상 연락처 (선택사항) |
| 메모 | 특이사항 등 메모 |

3. **저장**을 클릭합니다.

#### 입주자 상태 변경 (활성/비활성)

- 퇴소한 입주자는 **비활성**으로 전환합니다.
- 비활성 입주자는 대시보드에 표시되지 않습니다.

### 13.3 계좌 관리

**설정 > 계좌 관리** 에서 입주자별 계좌를 추가·수정합니다.

#### 계좌 추가

1. 계좌를 추가할 입주자를 선택합니다.
2. **+ 계좌 추가** 버튼을 클릭합니다.
3. 다음 정보를 입력합니다:

| 항목 | 설명 |
|---|---|
| 계좌 레이블 | 계좌 별칭 (예: KB국민통장, 농협카드) |
| 계좌번호 | 실제 계좌번호 |
| 초기 잔액 | 시스템 사용 시작 시점의 잔액 |
| 초기 잔액 기준일 | 초기 잔액 기준 날짜 (이 날짜 이후 거래부터 잔액 계산에 반영) |

4. **저장**을 클릭합니다.

💡 **팁**: 초기 잔액 기준일은 정확하게 설정해야 잔액 계산이 올바르게 됩니다. 예를 들어 2024년 1월 1일부터 시스템을 사용한다면, 2023년 12월 31일 기준 잔액을 초기 잔액으로 입력하고 기준일을 2023-12-31로 설정합니다.

### 13.5 자동분류 규칙 관리

### 13.7 데이터 초기화/마감

⚠️ **경고**: 이 탭의 작업은 **되돌릴 수 없습니다**. 반드시 신중하게 진행하세요.

**설정 > 데이터 초기화/마감** 탭에는 두 가지 기능이 있습니다.

#### (1) 연도별 데이터 마감 (센터장·관리자)

마감할 연도의 거래를 **`archive_YYYY` 컬렉션에 백업**하고 계좌의 기초잔액을 갱신하는 작업입니다. 마감 후 해당 연도 데이터는 조회 전용 상태가 됩니다.

💡 **영수증·통장사진은 삭제되지 않습니다.** 마감 시 해당 연도의 이미지는 저장 공간 절약을 위해 저해상도로 **압축하여 그대로 보관**됩니다(아카이브에서 계속 조회 가능). 실제 파일 삭제는 **전체 초기화**에서만 이루어집니다.

1. **마감할 연도**를 선택합니다.
2. 마감 전 체크리스트를 확인합니다:
   - 해당 연도의 모든 보고서가 최종 결재(confirmed) 상태인지 확인
   - 미결 거래(카테고리 미지정 등)가 없는지 확인
3. **📦 마감 실행** 버튼을 클릭하고 확인 메시지에 따라 최종 확인합니다.
4. 마감 이력은 같은 화면에서 조회할 수 있습니다.

💡 **팁**: 마감 전 반드시 보고서 전체를 엑셀/PDF로 백업해 두세요.

#### (2) Firebase 전체 초기화 (관리자 전용)

모든 거래·계좌·입주자·보고서 데이터를 삭제하는 작업입니다. **절대 되돌릴 수 없으므로** 시스템을 완전히 새로 시작하는 예외적인 경우에만 사용하세요.

### 13.8 예산 관리

**설정 > 예산 관리** 에서 입주자별 **연간 지출 예산**을 카테고리별로 설정합니다. 등록한 예산은 [연간 통계](#12-연간-통계)에서 예산 대비 실적으로 비교됩니다.

### 13.9 권한 관리 (관리자 전용)

**설정 > 권한** 에서 역할(입력자/담당자/팀장/센터장/관리자)별로 각 기능의 접근 권한을 세부 조정할 수 있습니다.

- 거래 입력/수정/삭제, 일괄 삭제, 순서 변경, 자산이동, 카테고리 편집, CSV 내보내기
- 엑셀 업로드, 증빙 업로드, 영수증 출력, 통장 사진 업로드
- 보고서 작성/수정/삭제/회수, 결재(1차·최종)·반려
- 설정(직원/입주자/계좌/고정항목/마감/초기화) 접근

변경 후 저장하면 각 사용자의 **다음 로그인부터** 적용됩니다.

⚠️ **주의**: 결재(제출·1차 결재·최종 결재·반려) 관련 핵심 권한은 결재 흐름의 무결성을 위해 역할에 따라 고정되어 있습니다.

## 14. 모바일 사용법

### 14.1 모바일 화면 구성

스마트폰(작은 화면)으로 접속하면 모바일 최적화 뷰가 자동으로 활성화됩니다.

모바일 화면 하단에 **내비게이션 바**가 표시됩니다:

| 아이콘 | 메뉴 | 설명 |
|---|---|---|

| 📋 | 내역 | 거래내역 조회 |
| ✏️ | 입력 | 수기 입력 폼 |
| 📊 | 보고서 | 보고서 목록 및 결재 |

⚠️ **입력자 역할**: 입력자는 보고서 탭이 표시되지 않습니다.

### 14.2 모바일에서의 주요 기능

#### 입주자 카드 조회 (홈)

- 담당 입주자의 카드가 세로로 나열됩니다.
- 카드를 탭하면 해당 입주자의 거래내역으로 이동합니다.

#### 거래내역 조회 (내역)

1. **내역** 탭을 탭합니다.
2. 입주자와 기간을 선택합니다.
3. 거래 목록이 표시됩니다.
4. 각 거래 항목을 탭하면 상세 내용을 확인할 수 있습니다.

#### 수기 입력 (입력)

1. **입력** 탭을 탭합니다.
2. 입주자와 계좌를 선택합니다.
3. 거래 정보를 입력합니다.
4. 스마트폰 카메라로 영수증을 바로 촬영하여 증빙으로 첨부할 수 있습니다.
5. **저장**을 탭합니다.

💡 **팁**: 영수증 첨부 시 **카메라로 직접 촬영** 옵션을 사용하면 현장에서 바로 증빙을 등록할 수 있습니다.

#### 보고서 (보고서)

1. **보고서** 탭을 탭합니다.
2. 결재 대기 목록이 표시됩니다.
3. 보고서를 탭하여 내용을 확인하고 결재(승인/반려)할 수 있습니다.

### 14.3 모바일 사용 시 주의사항

- 엑셀 업로드 기능은 모바일에서 제한될 수 있습니다. 엑셀 업로드는 PC 환경을 권장합니다.
- 드래그앤드롭 기능(거래 순서 변경)은 모바일에서 길게 탭한 후 드래그합니다.
- 화면이 작으면 일부 테이블 열이 잘릴 수 있습니다. 가로로 스크롤하여 확인하세요.

## 15. 자주 묻는 질문 (FAQ)

### Q1. 로그인이 되지 않아요.

**A.** 다음 사항을 확인하세요:

1. **아이디와 비밀번호**를 정확히 입력했는지 확인합니다. (대소문자 구분)
2. **Caps Lock**이 켜져 있지 않은지 확인합니다.
3. 계정이 시스템에 등록되어 있는지 관리자에게 문의합니다.
4. 브라우저 캐시를 삭제하고 다시 시도합니다. (Ctrl+Shift+Delete)

---

### Q2. 잔액이 실제와 다르게 표시돼요.

**A.** 잔액 계산은 **초기 잔액 + 초기 잔액 기준일 이후의 거래 합산**으로 이루어집니다. 다음을 확인하세요:

1. **설정 > 계좌 관리**에서 해당 계좌의 **초기 잔액**과 **기준일**이 올바르게 설정되어 있는지 확인합니다.
2. 기준일 **이전** 날짜의 거래는 잔액에 반영되지 않습니다.
3. **취소** 유형의 거래는 잔액에 포함되지 않습니다.
4. **자산이동** 거래는 출금 계좌에서는 차감, 입금 계좌에는 합산됩니다.

---

### Q3. 엑셀 파일을 업로드했는데 거래가 인식되지 않아요.

**A.** 다음을 확인하세요:

1. **지원하는 은행**의 파일인지 확인합니다. (KB국민, NH농협, 우리, 신한은행)
2. 은행 인터넷뱅킹에서 **엑셀(XLS/XLSX) 형식**으로 정확히 내려받았는지 확인합니다.
3. 파일을 열어보고 형식이 변경되지 않았는지 확인합니다. (다른 형식으로 저장하면 인식 안 될 수 있음)
4. 파일 용량이 너무 크지 않은지 확인합니다. (10MB 이하 권장)
5. 지원하지 않는 형식이라면 **수동 입력 템플릿**을 활용하세요.

---

### Q4. 보고서를 제출했는데 팀장이 보이지 않는다고 해요.

**A.** 다음을 확인하세요:

1. 입주자 정보에서 **담당 팀장**이 올바르게 지정되어 있는지 확인합니다. (**설정 > 입주자 관리**)
2. 팀장이 로그인했을 때 **보고서 탭의 숫자 뱃지**를 확인하도록 안내합니다.
3. 팀장의 역할이 **팀장**으로 설정되어 있는지 확인합니다. (**설정 > 직원 관리**)

---

### Q5. 고정항목을 입력했는데 중복으로 입력됐어요.

**A.** 시스템은 같은 달에 동일한 고정항목이 이미 입력되어 있으면 중복 입력을 차단합니다. 그러나 이미 중복 입력이 된 경우:

1. **거래내역**에서 중복된 거래를 확인합니다.
2. 잘못 입력된 거래를 **체크박스로 선택**한 후 **삭제**합니다.

중복 방지는 **fixedItemId** 기준으로 작동합니다. 고정항목을 삭제 후 다시 등록하면 새로운 fixedItemId가 부여되어 이전 입력 기록이 초기화됩니다.

---

### Q6. 증빙(영수증) 사진이 업로드되지 않아요.

**A.** 다음을 확인하세요:

1. **Google 계정 인증**이 되어 있는지 확인합니다. (관리자에게 문의)
2. 파일 크기 상한을 확인합니다. 시스템이 이미지를 자동 압축하지만, **이미지 15MB · HEIC 6MB · PDF 등 8MB**를 넘으면 업로드가 거부됩니다. 초과 시 사진을 다시 촬영하거나 용량을 줄여 올리세요.
3. 지원하는 이미지 형식인지 확인합니다. (JPG, PNG, GIF, HEIC 등)
   - 💡 iPhone **HEIC**는 브라우저에서 압축되지 않아 원본 그대로 저장됩니다. 용량 절약을 위해 가능하면 **JPG**로 올리는 것을 권장합니다.
4. 브라우저에서 **팝업이 차단**되어 있지 않은지 확인합니다. (Google 인증 창이 차단될 수 있음)
5. 인터넷 연결이 안정적인지 확인합니다.

---

### Q7. 카테고리 자동분류가 잘못 적용돼요.

**A.** 자동분류 규칙을 수정하거나 추가하세요:

1. **설정 > 자동분류 규칙**으로 이동합니다.
2. 잘못 분류되는 키워드를 찾아 해당 규칙의 카테고리를 수정합니다.
3. 새로운 규칙이 필요하면 **+ 규칙 추가**로 추가합니다.

즉각적인 수정이 필요하면:
- 업로드 **미리보기 화면**에서 직접 카테고리를 수정합니다.
- 저장 후 **거래내역에서 카테고리 칩 인라인 편집**으로 수정합니다.

💡 **팁**: 입주자별 전용 규칙을 만들면 해당 입주자의 거래에만 특별한 분류를 적용할 수 있습니다.

---

### Q8. 데이터 마감을 실수로 했어요. 되돌릴 수 있나요?

**A.** ⚠️ **데이터 마감은 되돌릴 수 없습니다.** 마감된 데이터는 아카이브 컬렉션으로 이동되며, 조회만 가능합니다.

마감 전 반드시:
- 모든 보고서가 최종 결재(confirmed) 상태인지 확인
- 필요한 데이터를 엑셀/PDF로 백업
- 관리자와 충분히 협의

실수로 마감한 경우, 기술 지원팀에 즉시 연락하여 데이터베이스 복구를 요청하세요.

### B. 잔액 계산 공식

```
현재 잔액 = 초기 잔액
           + Σ(기준일 이후 수입 거래)
           - Σ(기준일 이후 지출 거래)
           + Σ(기준일 이후 자산이동 입금)
           - Σ(기준일 이후 자산이동 출금)
           ※ 취소 거래는 잔액 계산에서 제외
```

### C. 보고서 상태 코드

| 상태 코드 | 한국어 | 설명 |
|---|---|---|
| `draft` | 초안 | 작성 중 또는 반려된 상태 |
| `submitted` | 제출됨 | 담당자가 제출, 팀장 결재 대기 |
| `team_approved` | 1차 결재 | 팀장 결재 완료, 센터장 결재 대기 |
| `confirmed` | 최종 결재 | 센터장 최종 결재 완료 |
