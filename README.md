## 🎯 주요 기능

### 거래 관리
- ✅ 수기 입력 (날짜/계좌/금액/분류, 자산이동·취소·환불)
- ✅ 파일 업로드 (KB/NH/우리/신한 은행·카드, SMS XML, HTML-XLS 자동 파싱)
- ✅ 고정항목 (매월 반복 거래 자동화)
- ✅ 거래 필터/컬럼 정렬/수정/삭제/일괄 삭제
- ✅ 목록 뷰 · 달력 뷰 전환, CSV 내보내기
- ✅ 중복 거래 자동 감지, 수동 입력 템플릿

### 보고서 & 결재
- ✅ 월간 보고서 자동 생성 (수입/지출/계좌현황/분류별 분석/자동 요약)
- ✅ 3단계 결재 흐름 (담당자 → 팀장 → 센터장)
- ✅ 의견란 (각 단계별 검토 의견)
- ✅ 반려/수정 처리 + 담당자 제출 회수(recall)
- ✅ 엑셀 저장, 인쇄/PDF (A4 최적화)

### 통계
- ✅ 연간 통계 (월별 차트, 카테고리 순위, 예산 대비 실적)
- ✅ 월별 추이

### 설정 & 관리
- ✅ 직원/입주자/계좌 관리
- ✅ 카테고리 + 자동분류 규칙 (공통/입주자별)
- ✅ 고정항목 관리
- ✅ 연간 예산 관리
- ✅ 데이터 초기화/마감
- ✅ 역할별 권한 커스터마이징 (관리자)

### 증빙 관리
- ✅ 이미지 업로드 (Firebase Storage, 자동 압축)
- ✅ 영수증 미리보기 + A4 일괄 출력 (2×4 격자)
- ✅ 통장 사진 관리 (계좌 관리 · 대시보드 퀵 액션)

### 접근성
- ✅ PWA (크롬/엣지 설치형 앱)
- ✅ 모바일 하단 네비게이션 + 반응형 UI

## 👥 역할 & 권한

| 역할 | 권한 |
|------|------|
| **입력자** | 거래 입력/수정 전용 (보고서·설정 접근 불가) |
| **담당자** | 거래 입력·엑셀·증빙, 보고서 작성 및 제출/회수 |
| **팀장** | 담당자 권한 + 1차 결재 (승인/반려) + 설정(직원/입주자/계좌) |
| **센터장** | 팀장 권한 + 최종 결재 (승인/반려) + 데이터 마감 |
| **관리자** | 모든 권한 + 권한 커스터마이징 + 전체 초기화 |

> 위 권한은 기본값이며, 관리자가 **설정 → 권한** 에서 역할별로 세부 조정할 수 있습니다.

## 🚀 시작하기

### 1. 로그인
```
웹사이트 접속 → ID/PW 입력 → 로그인
```

### 2. 기본 설정 (관리자)
- 직원 등록
- 입주자 등록
- 계좌 등록 (초기잔액, 기준일)
- 카테고리 설정

### 3. 거래 입력 (담당자)
- 엑셀 업로드 (은행 거래)
- 미분류 항목 카테고리 지정
- 수기입력 (누락 항목)

### 4. 월간 보고서 (담당자 → 팀장 → 센터장)
- 거래 완성 후 보고서 작성
- 담당자 의견 작성
- 팀장 1차 결재
- 센터장 최종 결재

## 💡 주요 팁

1. **엑셀 파일은 은행 다운로드 형식 그대로 사용**
   - KB/NH/우리/신한 지원

2. **초기잔액 & 기준일이 정확해야 함**
   - 잔액 계산: 초기잔액 + (기준일 이후 거래)

3. **고정항목 설정 후 월별 일괄 입력**
   - 급여, 공과금 등 고정액 자동화

4. **보고서 제출 전 충분히 검토**
   - 제출 후는 팀장이 반려해야 수정 가능

5. **중복 거래는 엑셀 업로드 시 자동 감지**
   - 미리보기에서 행 삭제 가능

6. **월말 며칠 전에 거래 완성**
   - 보고서 작성 여유 시간 확보

## 🔧 기술 정보

### 파일 구조
```
/public
  ├── index.html              # 전체 HTML + CSS
  ├── app.js                  # 전역 초기화 및 이벤트 바인딩
  ├── constants.js            # 상수 정의
  ├── state.js                # 전역 상태
  ├── parser-config.js        # 은행별 엑셀 파서 설정
  ├── manifest.json           # PWA 매니페스트
  ├── sw.js                   # 서비스 워커 (오프라인/설치)
  ├── modules/                # 기능별 모듈
  │   ├── auth.js
  │   ├── core.js
  │   ├── dashboard.js
  │   ├── transactions.js
  │   ├── report.js
  │   ├── settings.js
  │   ├── modals.js
  │   └── permissions.js      # 역할별 권한 레이어
  ├── services/               # 외부 서비스
  │   ├── firestore.js
  │   ├── image.js            # 이미지 압축 유틸
  │   └── storage.js          # Firebase Storage 업로드/삭제
  ├── utils/                  # 유틸리티
  │   └── ui.js
  └── icons/                  # PWA 아이콘

firestore.rules               # Firestore 보안 규칙 (프로젝트 루트)
```

### Firestore 컬렉션
```
users, clients, accounts, transactions, categories, reports,
config(+permissions), fixedItems, budgets, excelUploads, archive_YYYY
```

### 인증 방식
- Firestore `users` 컬렉션의 userId/password 직접 비교
- sessionStorage 기반 세션 유지
- Firebase Auth 미사용
